# Welcome

This repository contains experiments and prototypes. See `ARStudioPrototype/` for a simple example of integrating augmented reality with Roblox Studio.

## O.S.A.I.–ROFAM + Quantum Feedback Engine

The file `osai_rofam_qfe.py` implements a small demonstration of a legal brief generator that logs contradictions and computes a symbolic ROFAM score. Run it directly and enter a statement to receive a formatted brief:

```bash
python osai_rofam_qfe.py
```

Unit tests can be executed with `pytest`.
