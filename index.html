RAW AI Framework

Historical Research & Analysis Tool

Understanding This Tool & Transparency

This tool runs entirely in your web browser using JavaScript to prepare your research context. When you request AI analysis, the complete "Georgetown RAW AI Framework Super Prompt" (visible below) is sent to Google's Generative Language API. This API then uses the Gemini 2.0 Flash model to generate the structured analysis and suggestions based on the context you provide and the framework's detailed instructions.

What's Happening:

  1. You define your research project parameters.
  2. Your "RAW AI Blueprint Configuration" JavaScript generates specific data points or instructions for the AI.
  3. The tool combines *all* your inputs with the comprehensive "Georgetown RAW AI Framework Super Prompt."
  4. This complete super-prompt is sent to Gemini 2.0 Flash.
  5. Gemini, utilizing the detailed instructions in the super-prompt and conceptually aware of the vast resources listed (though it does not browse them live), performs the "Quantum Journey" analysis.

Data Handling:

No sensitive data is stored on external servers by this application. Your inputs are used to construct the AI prompt in your browser.

⚠️ Warning about Custom JavaScript: The "RAW AI Blueprint Configuration" section allows you to write and execute custom JavaScript code within your browser. This offers powerful customization but requires caution.
